# 权限管理：权限组页面与执行边界

状态：2026-11-06 工作区实现。当前采用单一 V2 动作权限模型，见 [权限组合同](permission-groups.md)。未发布的 V1 功能组、迁移、升级预览、nil 全权回退及逐 Agent 直接策略已删除。

## 页面与身份

/permissions 使用同一工作区内的“权限组 / Agent 管理”双视图。左栏负责对象切换、搜索和选择，右栏展示当前对象的完整详情，不在同一侧栏中叠加两套列表。权限组视图保留动作、条件、主机范围和一个只读的当前组成员列表；Token 只在 Agent 详情中管理。Agent 视图左侧为 Agent 列表，右侧展示权限组、当前 Token、Token 历史、身份和活动状态。

Agent（内部标识仍为 principal）独立保存稳定 ID、启停、权限组绑定和 Token 计数；没有 Agent 级动作覆盖。新建 Agent 不要求选择权限组，统一进入缺省组，之后可在 Agent 详情中修改；从权限组的 MCP Token 面板创建 Agent 也遵循同一规则，并直接打开该 Agent 的详情。初始缺省组动作为空、主机范围 all。仅显式 issue_token:true 或单独调用 token API 才签发 Token。

一个 Agent 同时只有一个当前 Token。普通签发在已有当前 Token 时拒绝；轮换通过原子替换完成，旧 Token 立即停止认证并进入历史。当前 Token 显示 ID、创建时间、可选到期时间和最近使用时间；历史记录只用于审计和追踪，可单独清空，不能恢复为有效 Token。UI 不再建立“客户端凭据”子对象，也不要求输入客户端名称。

组内共享策略不会合并 Agent namespace 或 MCP transport owner。管理员身份在人端单独管理，业务权限组不能授予 Admin 角色。Agent Token 仍只允许 MCP，不能进入 WebUI、REST 或管理面。

页面仅显示动作树和当前支持的参数条件；没有 V1 选择器、功能组编辑器或升级入口。动作分类默认全部收起，只展示会话、终端与通道、文件等一级标题；搜索或切换效果筛选时才自动展开匹配分类。Agent 支持搜索、状态筛选、创建、启停、修改权限组、Token 生命周期、删除预览与删除；权限组支持名称、复制、启停、缺省引用和删除预览。认证及权限页使用 [共享主题](auth-page-themes.md)。

## 执行边界

MCP 的能力出口检查当前策略，DSL 只使用鉴权接入点，不修改语法、参数、解析与执行行为。别名展开后的动作、实际参数分支、资源 restriction、namespace 和主机身份共同参与判断。未知动作/条件和未列出动作拒绝；存储及 HTTP 不接受旧 functions 字段。

主机范围使用稳定身份，主机改名不丢授权，同名重建不继承旧身份。共享配置修改需 all 范围。复制及任务访问检查两端。文件字节证据和不支持形式的保守拒绝见 [文件权限](file-operation-permissions.md)，不扩展普通 DSL 读取参数。

组变更、成员迁移、停用与凭据撤销取消受影响的请求和后台传输，保留任务回执。SSE 登记检查实际 message 存活状态和本次授权修订；旧消息不能借权限恢复重新登记工作。

当前支持 allow/deny；审批回放和 #196/#197 的词汇/多组继承仍为后续工作。已有审阅门控的 Agent 操作继续拒绝，操作者可在 WebUI 执行。终端操作遵循目标 OS 权限，已发生的远端写入不承诺回滚。

权限目录同时提供动作风险、DSL/工具/WebUI 可达面、参数证据和组合依赖。`/permissions` 可将当前草稿与一条 DSL 命令提交到只读预览，逐项显示缺少的授权；预览不执行命令，也不创建会话或后台任务。执行前的 profile/extension 绑定会随着实际 handler 进入执行层，名称在检查后发生重建或改指向时拒绝运行。

权限组、Agent、缺省组、角色入口和凭据变更写入结构化审计；Agent MCP 拒绝记录动作与原因。审计事件不包含密码、token、Cookie、请求正文或连接秘密。
