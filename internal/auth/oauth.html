OAuth 接入

客户端只需填写 Termcp 的 MCP 地址。登录、确认、Agent 创建和凭据续期由 Termcp 内置 OAuth 服务完成。

OIDC
用户身份来自管理员配置的 OIDC 身份源身份源的 Token 不会交给 MCP 客户端；Termcp 只保存本地签名索引与加密后的接入状态。

保存后立即生效并保留到重启。修改公开地址、身份源或启用状态会终止旧 OAuth 凭据；静态 Token 不受影响。

在身份源登记的回调地址

在 OIDC 应用配置中登记这个精确地址；修改公开访问地址后需要同步更新。

MCP 客户端地址

在支持 OAuth 的 MCP 客户端中只填写这个 URL。客户端会发现授权服务并打开浏览器。
